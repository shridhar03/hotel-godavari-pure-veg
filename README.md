# Hotel Godavari Pure Veg

A production-ready, visually rich frontend website for **Hotel Godavari Pure Veg**, a premium pure-vegetarian hotel and restaurant inspired by the Godavari river.

The site uses [three.js](https://github.com/mrdoob/three.js) as its core 3D engine to create an immersive, river-themed experience: flowing water, soft light, and calm motion that reflect the hotel's identity.

## Goals

- **Immersive 3D hero**: a real-time Godavari river scene built with three.js.
- **Restaurant**: showcase the pure-vegetarian menu, signature dishes and dining spaces.
- **Hotel**: present rooms, amenities and the guest experience.
- **Bookings and contact**: clear calls to action for table reservations and room enquiries.
- **Production quality**: fast loading, responsive on phones and desktops, accessible, and SEO-friendly, with graceful fallbacks when WebGL is unavailable.

## Tech stack

- [three.js](https://threejs.org/) for 3D rendering
- Modern HTML, CSS and JavaScript (build tooling to be decided)
